Enhanced Document Grouping Implementation Guide
Phase 1: Understanding the Problem
Current Situation:

Your system groups documents ONLY by exact invoice number match
Same invoice numbers (like "455") are being reused for completely different shipments
This creates false groupings - 20 different shipments all grouped as one
Valid document pairs aren't matching because they have slightly different invoice formats

Goal:

Create ~1,800 proper groups (instead of current incorrect groupings)
Match documents that actually belong to the same shipment
Handle invoice number variations and duplicates

Phase 2: Core Logic Changes
What to Change:

Replace Simple Invoice Matching with Composite Key

Current: Groups by anchor_key (invoice number) only
New: Group by combination of:

Last 4 digits of invoice
Vehicle number (normalized)
Invoice date

Why This Works:

Invoice "455" + Vehicle "TN XC 1234" + Date "2023-01-15" = Unique shipment
Invoice "455" + Vehicle "AP 29 TB 9277" + Date "2022-09-16" = Different shipment
These become two separate groups instead of one incorrect group

Phase 4: Database Changes
Step 1: Clean Up Existing Duplicates
Run this SQL to remove duplicate documents:
sql-- This will delete duplicate documents, keeping only the first one
WITH duplicates AS (
SELECT id, ROW_NUMBER() OVER (
PARTITION BY
user_id,
document_type,
anchor_key,
raw_json->>'vehicle_number',
raw_json->>'invoice_date'
ORDER BY created_at ASC
) as rn
FROM parsed_documents
)
DELETE FROM parsed_documents WHERE id IN (
SELECT id FROM duplicates WHERE rn > 1
);
Step 2: Update Table Constraints
sql-- Drop old constraint
ALTER TABLE document_groups
DROP CONSTRAINT IF EXISTS document_groups_user_id_invoice_number_key;

-- Add new constraint on composite key
ALTER TABLE document_groups
ADD CONSTRAINT document_groups_user_id_group_key_key
UNIQUE (user_id, group_key);

Key Concepts to Remember

Composite Key = Real Shipment Identity

Invoice alone is not unique
Vehicle + Date + Invoice = Unique shipment

Normalization is Critical

Vehicle "TN XC 1234 2345" and "TN XC 1234" should match
Remove extra trip numbers, spaces, special characters

Duplicates Must Go

Same document appearing multiple times breaks grouping
Keep only one copy of each unique document

This Creates More Groups, Not Fewer

Current: Few large incorrect groups
After: Many smaller correct groups (~1,800)
